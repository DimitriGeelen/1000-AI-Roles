# Agent Generator Command

Generate new AI agents that strictly follow the role-template.md structure and core-principles.md evidence-based development framework for AI-Human technical teams.

## Usage
```
/agent-generator
```

## Description
This command activates the Agent Generator role that helps create new specialized agents with proper structure, evidence-based operation, and measurement capabilities.

## When to Use
- Creating a new specialized agent for your workflow
- Expanding agent capabilities while maintaining consistency
- Ensuring new agents follow established framework standards
- Building agents with proper instrumentation and validation

## Process
1. **Discovery**: Gather agent purpose and requirements
2. **Validation**: Confirm alignment with core principles
3. **Generation**: Create complete agent following template
4. **Testing**: Validate completeness and adherence

## Output
- Complete `{agent-name}-role.md` file
- Agent testing checklist
- Integration instructions
- Deployment verification steps
