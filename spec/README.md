# Specifications Directory

This directory contains technical specifications and interface definitions.

## Files

- **`planner-interface.md`** - Standardized interface specification for all planner agents (Azure DevOps, Jira, Monday, etc.)

## Purpose

These specifications ensure:
- Platform-agnostic agent communication
- Consistent interfaces across different project management systems
- Proper decoupling between agents and specific platforms
- Future extensibility for new planner implementations
